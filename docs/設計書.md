## 1. はじめに

本書は、`COBOL2Java` の目的、構成、機能、データ、セキュリティ、運用観点を引継ぎ可能な粒度で整理する設計書である。

## 2. システム概要

COBOL ソースをオブジェクト指向 Java へ変換する GUI/CLI ツール

### 2.1 利用者

- レガシー移行担当
- Java 開発者
- 品質レビュー担当

### 2.2 スコープ内

- COBOL 解析
- DATA/PROCEDURE DIVISION 変換
- ベンダ方言対応
- Java クラス生成
- 多言語 GUI
- CLI 一括変換

### 2.3 スコープ外

- 全 COBOL 方言の完全保証
- 業務テストの自動代替
- Java 実行環境へのデプロイ

## 4. データ・設定モデル

| データ | 形式 | 説明 |
|---|---|---|
| 入力 | .cbl/.cob/.cobol | COBOL ソース |
| 変換設定 | CLI/GUI options | パッケージ名、エンコーディング、方言 |
| 出力 | .java | 生成 Java ソースとレポート |

## 5. 機能仕様

| ID | 機能 | 仕様 |
|---|---|---|
| F-01 | 方言検出 | COBOL 構文パターンからベンダ方言を推定する。 |
| F-02 | 構文解析 | DATA DIVISION と PROCEDURE DIVISION を段階的に解析する。 |
| F-03 | Java 生成 | データクラス、サービス、ファイルハンドラ等に分割して出力する。 |
| F-04 | GUI/CLI | 対話操作と CI/CD 向け一括変換を両立する。 |

## 6. セキュリティ・品質

- 基幹系ソースをローカル処理し、外部送信を前提にしない。
- 生成 Java はレビュー・単体テストを経て利用する。

## 7. デプロイ・運用

- python main.py で GUI
- python main.py -i ./samples -o ./output --vendor auto
- pytest/test_conversion.py で回帰確認

## 8. 既知の制約と今後の拡張

- 自動変換・自動判定を含む機能は、利用者または担当者レビューを前提とする。
- 本番利用前に対象データ、権限、ログ、バックアップ、例外処理を運用環境に合わせて確認する。
- README と実装差分が出た場合は、実装側を正として本書を更新する。
